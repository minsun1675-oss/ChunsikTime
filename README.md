# 오늘의 공부 — 춘식이표 개인 공부 앱 (Android v0.1 소스 프로젝트)

## 상태

**소스코드로 제공하는 첫 번째 개발 버전**입니다. Android Studio에서 컴파일/실행 테스트가 이루어지지 않았으며, APK는 포함되어 있지 않습니다. 이 파일을 설치 파일로 오인하지 마세요.

**기준:** 삼성 갤럭시 S23+, 안드로이드, 오프라인 개인 사용. 광고/로그인/서버 없음.

## Android Studio로 실행

1. Android Studio 최신 버전을 설치하고 Android SDK Platform **35** 및 JDK **17**을 준비합니다.
2. `ChunsikStudy` 폴더를 **Open**으로 엽니다.
3. 프로젝트 Gradle은 Android Gradle Plugin `8.9.2`, Kotlin `2.1.20`, Compose BOM `2025.04.01`을 사용합니다. Gradle **8.11.1**이 필요합니다. 이 배포본에는 `gradle-wrapper.jar`가 없으므로, Gradle 설치 후 `gradle wrapper --gradle-version 8.11.1`로 wrapper를 생성하거나 Android Studio에서 호환 Gradle 설정을 구성해야 합니다.
4. Gradle 동기화 후 **Build > Build APK(s)** 를 실행합니다.
5. 생성된 APK를 S23+에 설치합니다. 설정에서 **화면 위에 표시**, **방해 금지 접근**, **알림** 권한을 허용해야 관련 기능을 사용할 수 있습니다.
6. APK 실행이 오류 없이 되는지 먼저 확인한 뒤 실제 공부 데이터를 넣어주세요. 아직 테스트되지 않은 개발판입니다.

> 이 대화에서 SDK 및 Gradle 실행 환경이 제공되지 않아 APK 빌드 및 기기 실사용 검증을 완료하지 못했습니다. 최초 Sync/Build 단계에서 호환성 수정이 필요할 수 있습니다.

## 첫 개발판에 소스가 포함된 기능

- 과목 추가/삭제(관련 기록이 있으면 삭제 차단), 오프라인 SQLite 저장
- 단일 과목 타이머, 시작/일시정지/이어하기/종료, 자정 기준 기록 분리
- 포그라운드 서비스 및 선택 가능한 플로팅 타이머, 드래그/일시정지/팝업 닫기
- 방해 금지 연동: 권한이 있을 때 시작 시 적용, 종료 시 복원(운영체제 제한 있음)
- 주간/날짜별 30분 단위 시간표 추가, 시간 중복 검사, 학습 목표 연동
- 월간 캘린더, 시험/개인공부/휴식 유형, 휴식일 목표 제외, D-day
- 일간 원형/주간 막대/월간 과목별 막대 및 월별 추세 통계
- 5개 기본 테마, 랜덤 응원 문구, 메인 탭 5개
- 실행 시 월별 로컬 JSON 백업, 6개월 넘은 내부 백업 정리, 수동 파일 가져오기/내보내기

## 아직 완료하지 않은 부분 (반드시 확인)

- 사용자 지정 테마 **추가·수정·삭제**, 사용자 응원 문구 편집
- 캘린더의 **슬라이딩 애니메이션**: 현재 날짜 선택 시 해당 주만 표시하는 단순 축소. 실제 아래 스와이프·좌우 스와이프는 초기 구현이므로 세로 스크롤과 충돌할 수 있음
- 시험·개인공부 **일정 알림 예약** 및 반복 일정의 개별 발생 건 수정
- 주차별 변경/추가 규칙 전체, 계획 **수정** UI (현재 추가/삭제 중심)
- 공부 기록 **정확한 시간 입력 수정** UI (현재 삭제·수동 추가, 1분 줄이기만 임시 구현)
- 공부 기록은 일시정지 시 DB에 분할 저장되므로 **확정 종료 때만 목표 갱신** 정책을 아직 완벽히 충족하지 않음
- 타이머 숫자는 현재 측정 구간에 대한 표시이며 그날 해당 과목 전체 누적 시간 표시와 다름
- 사용자 설정/과목 이름 변경, 완전한 UI/접근성, 화면 크기별 테스트
- 삼성 One UI 8.5의 포그라운드 서비스, 제스처, 방해 금지 정책에 대한 실기기 검증
- Pretendard 폰트 파일 미포함(배포 권한/최적화 확인 전), Roboto/시스템 기본 글꼴 사용
- **백업 자동 생성은 정확히 매월 시각에 예약된 작업이 아닌, 해당 월에 앱을 처음 열었을 때 생성**

## 데이터 및 안전 메모

- 로컬 DB: `study.db`. 내부 자동 백업: `files/snapshots/backup-YYYY-MM-DD.json`.
- 내부 백업은 앱 삭제/휴대폰 초기화와 함께 사라질 수 있습니다. 외부 파일 내보내기로 별도 보관하세요.
- '백업 가져오기'는 현재 DB를 덮어씁니다. **가져오기 전 반드시 별도 백업을 내보내세요.**
- 강제 종료/재부팅은 앱에 종료 시각을 알려주지 않아 마지막 기록 시점과 실제 종료 시점에 차이가 발생할 수 있습니다. 약 15초 단위 체크포인트를 사용합니다.
- 화면에서 최근 앱을 밀어 제거하는 것은 시스템의 '강제 종료'와 다를 수 있으며 포그라운드 서비스가 계속 실행될 수 있습니다.
- 실측 배터리·메모리 절감량은 아직 검증되지 않았습니다.

## 중요 파일

- `app/src/main/java/com/chunsik/study/MainActivity.kt` — Compose UI 및 화면
- `app/src/main/java/com/chunsik/study/Store.kt` — SQLite, 통계 집계, JSON 백업
- `app/src/main/java/com/chunsik/study/StudyService.kt` — 타이머, 오버레이, 방해 금지
- `app/src/main/AndroidManifest.xml` — Android 권한 및 서비스 정의
